Modo de conexión

Precios y estimaciones de recursos disponibles. No necesitas una cuenta.

Configuración personal de Cursor

Añade el servidor a ~/.cursor/mcp.json. Si el archivo ya existe, añade la entrada gasfree4you al objeto mcpServers, conservando los demás servidores.

mcp.json
{
  "mcpServers": {
    "gasfree4you": {
      "url": "https://www.gasfree4you.com/mcp"
    }
  }
}

Guarda el archivo, reinicia Cursor y comprueba el servidor en los ajustes de MCP.

Documentación de Cursor ↗

Añadir desde Claude Code CLI

Ejecuta el comando en tu terminal. El ámbito user hace que el servidor esté disponible en tus proyectos.

Terminal
claude mcp add --transport http --scope user gasfree4you https://www.gasfree4you.com/mcp

Abre una nueva sesión de Claude Code y ejecuta /mcp para comprobar la conexión. Para cambiar de modo, elimina primero la entrada existente: claude mcp remove --scope user gasfree4you y luego añádela de nuevo.

Documentación de Claude Code ↗

Configuración de Codex

Añade este bloque a ~/.codex/config.toml. Si la entrada gasfree4you ya existe, actualízala sin crear un duplicado.

config.toml
[mcp_servers.gasfree4you]
url = "https://www.gasfree4you.com/mcp"

Reinicia el cliente. En Codex CLI, ejecuta /mcp y comprueba las herramientas disponibles.

Documentación de Codex ↗

Usa un cliente compatible con Streamable HTTP y cabeceras HTTP personalizadas. La clave API se configura manualmente, sin OAuth.

Envía la clave únicamente en una cabecera de conexión: X-API-Key: YOUR_API_KEY o Authorization: Bearer YOUR_API_KEY. Usa solo una de ellas. No envíes la clave en el chat, la URL ni los parámetros de las herramientas, y no publiques una configuración que la contenga.

Importante al hacer un pedido

Los pedidos de energía descuentan fondos del saldo de tu cuenta. Conecta tu clave solo a aplicaciones de confianza y revisa la dirección y los parámetros de la compra.

Si el agente indica que el resultado del pedido es desconocido o que se agotó el tiempo de espera, revisa primero el historial de operaciones en GasFree4You. No crees otro pedido hasta conocer el resultado del anterior.

El comportamiento de la confirmación depende del cliente de IA y de sus ajustes: puede que no aparezca una ventana de confirmación independiente.

MCP REFERENCEPara desarrolladores+

Cuatro herramientas disponibles. La autenticación se configura en las cabeceras HTTP de la conexión, no en los argumentos de la llamada.

Herramientas y parámetros MCP de GasFree4You
HerramientaParámetrosAcceso
estimate_transfer_feesender_wallet, recipient_walletSin clave
get_energy_pricesNingunoSin clave
get_account_balanceNingunoClave API
order_energywallet, energy, request_idClave API · de pago
  • energy: 65000, 130000 o 131000. El valor 130000 se normaliza a 131000.
  • Cada llamada de pedido compra un paquete, sin recarga adicional de TRX. El servicio determina la duración.
  • request_id: un UUID único para cada pedido nuevo. Conserva ese UUID y los mismos parámetros al reintentar el mismo pedido.
  • ORDER_PENDING_OR_UNKNOWN: revisa el historial en la aplicación o contacta con soporte; no reintentes con un UUID nuevo.
  • API_KEY_REQUIRED: configura la clave en las cabeceras de conexión.

MCP no ofrece historial ni seguimiento de pedidos, comprobación de sanciones para direcciones ni consultas independientes a la cadena. La herramienta de precios devuelve tarifas públicas, no una cotización personalizada exacta antes de un pedido.
