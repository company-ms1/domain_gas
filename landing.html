How TRON transfer fees work

USDT on TRON is a TRC20 token. Sending it requires TRON network resources, such as Energy and Bandwidth. If a wallet does not have enough resources, the network may use TRX to cover the transaction cost.

GasFree4you provides temporary TRON Energy delegation for supported transfers. This is a network resource service, not an exchange, investment product, wallet provider, or custody service.
