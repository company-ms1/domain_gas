# Миниблог GasFree4you — прототип

Главная страница и статья «Как завести свой кошелёк: от обычного способа до экзотического» на четырёх языках: английском, русском, испанском и индонезийском. Визуальный стиль продолжает основной сайт. Сами страницы не требуют JavaScript, пакетов или внешних шрифтов.

## Структура

```text
en/blog/                         Английские страницы
ru/blog/                         Русские страницы
es/blog/                         Испанские страницы
id/blog/                         Индонезийские страницы
  index.html                     Главная блога
  getting-started.html            Первая статья
blog/assets/blog.css             Общие стили
blog/content/welcome.json        Тексты главной страницы и интерфейса
blog/content/wallet.json         Статья о кошельках на четырёх языках
blog/assets/tron_wallet.py       Скачиваемый учебный Python-пример
scripts/build_blog.py            Генератор HTML
```

На главной: вступление → первая статья → три запланированных материала → темы → переход к сервису. В статье: ключи и seed-фраза → приложение → аппаратный кошелёк → контроль ключей → Python офлайн → активация аккаунта → памятка → FAQ. Ссылки на официальные источники размещены рядом с соответствующими разделами.

Рубрики: основы крипты, инструкции, о сервисе, обновления. Запланированные материалы и темы пока показаны как текст, без несуществующих ссылок или фильтров.

## Редактирование и просмотр

Редактируйте тексты интерфейса в `blog/content/welcome.json`, статью и её карточку — в `blog/content/wallet.json`. Код в статье берётся непосредственно из `blog/assets/tron_wallet.py`. Затем из корня проекта выполните:

```sh
python3 scripts/build_blog.py
python3 -m http.server 8000
```

Откройте `http://localhost:8000/ru/blog/index.html`. Переключатель языка сохраняет текущую страницу. Статические HTML-файлы можно открыть и напрямую.

Для ссылок используйте полные пути с `index.html` или `getting-started.html`: существующее правило Vercel перехватывает URL без расширения. Конфигурация сайта не менялась.

## Перед публикацией

Статья написана, но ещё не опубликована: на всех восьми страницах стоят `noindex,follow` и метка черновика у первого материала. Страницы пока не включены в sitemap и навигацию основного сайта. URL первой статьи `getting-started.html` сохранён, чтобы ранее выданные ссылки продолжали работать.

После редакторской вычитки уберите метки черновика и `noindex` в генераторе, пересоберите HTML, добавьте URL в sitemap и ссылку на блог в основной сайт. Canonical и взаимные hreflang уже предусмотрены.

## Python-пример

Пример использует `tronpy==0.6.1`. В статье приведена подготовка wheelhouse на совместимой онлайн-машине и установка с `--no-index` на офлайн-машине. Генерация не использует API и не активирует аккаунт в сети.

`--demo` использует публичный приватный ключ со значением 1. Адрес `TMVQGm1qAQYVdetCeGRRkTWYYrLXuHK2HC` нужен только для воспроизводимого вывода, переводить на него средства нельзя. Без флага используется системная случайность через `PrivateKey.random()`. Пример не создаёт seed-фразу и не реализует подпись/передачу транзакций.

Проверены demo-режим и два случайных запуска с запретом сетевых соединений. Адреса сверены независимым расчётом через secp256k1, Keccak-256 и Base58Check. Проверены ссылки, якоря, языковые связи и совпадение кода/вывода в четырёх HTML-версиях с исполняемым примером. Это проверка примера, а не аудит системы холодного хранения.

Дальнейшее расширение: отдельная запись на каждую статью с постоянным ID, рубрикой, датами, статусом и четырьмя переводами. Для текущей заготовки CMS не требуется.
