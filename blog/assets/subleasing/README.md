# Скриншоты Tronscan для статьи о сабаренде

Положите сюда три PNG-файла. Желательно сделать скриншоты Tronscan на английском: одни изображения используются во всех четырёх языковых версиях, подписи и alt переведены отдельно.

1. **01-client-payment-3-trx.png** — [оплата 3 TRX](https://tronscan.org/transaction/e5799b29e6d91ebc5a19239674f49c2ae1a17f26f0669e7edfb992e0db30bb83/overview). Покажите SUCCESS, сумму, From и To.
2. **02-energy-delegation.png** — [делегирование](https://tronscan.org/transaction/587d002556458a8ff559aac356185043ac1f9e8cb77e474fd8e4caa485dd81b7/overview). Покажите тип операции, ресурс ENERGY и Receiver. Важно отличать объём застейканных TRX от единиц Energy.
3. **03-usdt-transfer-fees.png** — [перевод 75 USDT](https://tronscan.org/transaction/2378593a461953cd7a55cd2122e32d6219eabf595d879c1b4d471914a9685841/overview). Покажите сумму, From, расход 64 285 Energy, Energy fee 0 и Bandwidth fee 0.345 TRX. При необходимости раскройте детали ресурсов.

Рекомендуемая ширина 1400–1800 px. Обрежьте лишние панели браузера, не обрезая проверяемые поля. Не меняйте значения и адреса. API показывает приблизительный эквивалент делегированных ресурсов: 65 008.56 Energy на момент проверки; отображение в интерфейсе может отличаться округлением/пересчётом. Поле balance в делегировании — не платёж клиента и не количество Energy.

После добавления изображений выполните из корня проекта:

```sh
python3 scripts/build_blog.py
```

Генератор встроит изображения во все четыре версии статьи. Пока файлов нет, отображаются карточки операций, подписи, UTC-время и ссылки Tronscan без сломанных изображений. Затем опубликуйте HTML и PNG вместе.

Проверка примера: API `https://apilist.tronscanapi.com/api/transaction-info?hash=...`, дата проверки 2026-09-22. Ключевые поля сохранены в `blog/content/subleasing-transactions.json`. Внутреннее списание с кабинета партнёра не подтверждается этими on-chain данными. Измеренное время 12 секунд до делегирования и 36 секунд до перевода USDT не является SLA.
