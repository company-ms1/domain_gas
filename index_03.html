    FAQ — частые вопросы

    Зачем вообще нужна аренда энергии TRON?

    Держатели стейкают TRX и получают ресурсы сети — энергию. Её можно временно делегировать активным отправителям, что позволяет платить меньше, чем стандартная комиссия TRX.

    На сколько переводов хватает энергии?

    Пакет действует на один перевод и отзывается сразу после первой операции или по таймауту (до часа).

    Это безопасно?

    Мы делегируем энергию, не забирая ваши средства и без доступа к приватным ключам. Вы переводите TRX только для оплаты пакета энергии.

    Для кого этот сервис?

    Для обменников, кошельков, OTC и любых сервисов с частыми переводами USDT/TRC20, а также для пользователей, не желающих держать большой остаток TRX на комиссиях.

    Есть ли API и UI-консоль?

    Да. Доступны UI для массовой раздачи энергии и REST API для полной автоматизации. Нажмите кнопку «API» вверху.
