Getting started

Sign in to your personal account and open the API tab to obtain your Base URL and API key.

Open account

Set these variables in your terminal. Copy the Base URL from your account without a trailing slash.

cURL / Shell
export BASE_URL="https://YOUR_API_BASE_URL"
export API_KEY="YOUR_API_KEY"

Send X-API-Key for balance, tariffs and orders. The fee estimate endpoint is public and needs no API key. Keep your key on your backend, not in browser code.

Check balance → estimate Energy → fetch tariffs → place an order

Energy is delegated to the wallet sending USDT. recipient_wallet in the estimator is the destination of the USDT transfer.

GET/v1/me/balance

Get balance

X-API-Key required

Returns the available service balance in TRX, with its SUN equivalent.

Request

cURL / Shell
curl "$BASE_URL/v1/me/balance" \
  -H "X-API-Key: $API_KEY"

Example response

JSON
{
  "balance_sun": 19795000,
  "balance_trx": 19.795
}
GET/v1/public/fee-estimate

Estimate required Energy

Public · no API key

Determines the required Energy package. With a sender address, it also checks the resources available in that wallet.

Parameters

recipient_wallet Required
Recipient TRON address. Used to determine whether 65,000 or 130,000 Energy is required.
sender_wallet Optional
Optional sender TRON address. Adds its Energy, Bandwidth and TRX balance to the estimate.

Recipient and sender

Request

cURL / Shell
curl "$BASE_URL/v1/public/fee-estimate?recipient_wallet=TTAFuzcJZyJidjNvbi9S9UviPaietqZ9if&sender_wallet=TTAFuzcJZyJidjNvbi9S9UviPaietqZ9if"

Example response

JSON
{
  "bandwidth_deficit": 0,
  "code": "SENDER_LACKS_ENERGY",
  "energy_deficit": 64991,
  "has_enough_bandwidth": true,
  "has_enough_energy": false,
  "has_enough_trx_for_bandwidth": true,
  "recipient_has_usdt": true,
  "recommended_trx_topup": "0",
  "required_energy": 65000,
  "sender_bandwidth_available": 515,
  "sender_energy_available": 9,
  "sender_trx_balance": "36.279462"
}

Recipient only

POST/v1/order

Order Energy

X-API-Key required

Delegates the selected Energy package to a TRON wallet and deducts its cost from your service balance.

Energy is valid for 1 hour after delegation or until the first transfer, whichever comes first.

If the wallet is not activated, we activate it before delegating Energy. Activation costs an additional 1.2 TRX.

Calculate the required Energy before ordering →

Request

cURL / Shell
curl -X POST "$BASE_URL/v1/order" \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "wallet": "TYourTronWalletAddress",
    "energy": 65000,
    "trx_topup": false,
    "trx_topup_amount": 0
  }'

Parameters

wallet Required
TRON address receiving the Energy delegation — the wallet that will send USDT.
energy Required
Energy amount from the current tariffs. Before every order, use GET /v1/public/fee-estimate to calculate the required package; do not choose it at random.
trx_topup Optional
Guaranteed cost coverage. A separate 0.5 TRX fee is deducted from the service balance. The method is selected automatically: 400 Bandwidth for 1 hour or 0.345 TRX sent to the sender wallet.
trx_topup_amount Optional
Use 0.345 when enabled and 0 when disabled. This is the service denomination, not the fee: do not use 0.5 here.

Only these two combinations are valid

Coverage off

JSON
{"trx_topup": false, "trx_topup_amount": 0}

Coverage on

JSON
{"trx_topup": true, "trx_topup_amount": 0.345}

price_trx includes only Energy. The 0.5 TRX coverage fee is charged separately.

trx_topup_sent=true means TRX was sent or a Bandwidth order was accepted; delegation may still be in progress. trx_topup_blockchain_tx_id can be null until the transaction hash is available. Your client does not need to poll Netts.

Example response

JSON
{
  "price_trx": 2.8,
  "balance_trx_after": 122.7
}

Examples are illustrative; tariff and order prices may differ.
