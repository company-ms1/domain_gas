GET /v1/me/balance

Get current balance in SUN and TRX.

Python 
import requests

BASE_URL = "https://YOUR_API_URL"
API_KEY = "YOUR_API_KEY"

r = requests.get(
    f"{BASE_URL}/v1/me/balance",
    headers={"X-API-Key": API_KEY},
    timeout=15
)
print(r.status_code)
print(r.json())
Response schema 
{
  "balance_sun": 123456789,
  "balance_trx": 123.456789
}

GET /v1/me/transactions

List recent transactions (top-ups, energy orders, etc.).

Python 
import requests

BASE_URL = "https://YOUR_API_URL"
API_KEY = "YOUR_API_KEY"

params = {"limit": 50}  # 1..500, default 50
r = requests.get(
    f"{BASE_URL}/v1/me/transactions",
    headers={"X-API-Key": API_KEY},
    params=params,
    timeout=20
)
print(r.status_code)
for item in r.json():
    print(item["id"], item["kind"], item["status"], item.get("energy"))

POST /v1/order

Create energy order for a TRON wallet.

⚠️ Use Idempotency-Key to avoid duplicate orders on retries.
Python 
import requests
import uuid

BASE_URL = "https://YOUR_API_URL"
API_KEY = "YOUR_API_KEY"

payload = {
    "wallet": "TX12345678901234567890123456789012",  # 34 chars, starts with 'T'
    "energy": 65000  # or 130000
}

headers = {
    "X-API-Key": API_KEY,
    "Idempotency-Key": str(uuid.uuid4()),  # optional but recommended
    "Content-Type": "application/json"
}

r = requests.post(
    f"{BASE_URL}/v1/order",
    headers=headers,
    json=payload,
    timeout=20
)
print(r.status_code)
print(r.json())
200 Response 
{
  "ok": true,
  "balance_sun_after": 999999,
  "balance_trx_after": 999.999,
  "price_trx": 2.9,
  "price_currency": "TRX",
  "external_status_code": 200,
  "external_order_id": null,
  "external_body": null,
  "tx_id": 12345
}
