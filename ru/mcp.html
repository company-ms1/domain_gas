Личная конфигурация Cursor

Добавьте сервер в ~/.cursor/mcp.json. Если файл уже существует, добавьте запись gasfree4you в его объект mcpServers, сохранив остальные серверы.

mcp.json
{
  "mcpServers": {
    "gasfree4you": {
      "url": "https://www.gasfree4you.com/mcp"
    }
  }
}

Сохраните файл, перезапустите Cursor и проверьте сервер в настройках MCP.

Документация Cursor ↗

Добавление через Claude Code CLI

Выполните команду в терминале. Область user делает сервер доступным в ваших проектах.

Терминал
claude mcp add --transport http --scope user gasfree4you https://www.gasfree4you.com/mcp

Откройте новую сессию Claude Code и выполните /mcp для проверки подключения. При смене режима сначала удалите прежнюю запись: claude mcp remove --scope user gasfree4you, затем добавьте её заново.

Документация Claude Code ↗

Конфигурация Codex

Добавьте блок в ~/.codex/config.toml. Если запись gasfree4you уже есть, обновите её, не создавая дубликат.

config.toml
[mcp_servers.gasfree4you]
url = "https://www.gasfree4you.com/mcp"

Перезапустите клиент. В Codex CLI выполните /mcp и проверьте доступные инструменты.

Документация Codex ↗

Используйте клиент с поддержкой Streamable HTTP и пользовательских HTTP-заголовков. API-ключ настраивается вручную, без OAuth.

Передавайте ключ только в заголовке подключения: X-API-Key: YOUR_API_KEY либо Authorization: Bearer YOUR_API_KEY. Используйте один из них. Не отправляйте ключ в чат, URL или параметры инструментов и не публикуйте конфигурацию с ключом.

Важно при заказе

Заказ энергии списывает средства с баланса вашего аккаунта. Подключайте ключ только к доверенным приложениям и проверяйте адрес и параметры покупки.

Если агент сообщает, что результат заказа неизвестен или истекло время ожидания, сначала проверьте историю операций в GasFree4You. Не создавайте новый заказ, пока не выяснен результат предыдущего.

Поведение подтверждения зависит от AI-клиента и его настроек: отдельное окно подтверждения может не появиться.

MCP REFERENCEДля разработчиков+

Четыре существующих инструмента. Авторизация задаётся в HTTP-заголовках подключения, а не в аргументах вызова.

Инструменты и параметры MCP GasFree4You
ИнструментПараметрыДоступ
estimate_transfer_feesender_wallet, recipient_walletБез ключа
get_energy_pricesНетБез ключа
get_account_balanceНетAPI-ключ
order_energywallet, energy, request_idAPI-ключ · платно
  • energy: 65000, 130000 или 131000. Значение 130000 нормализуется в 131000.
  • Один вызов заказа покупает один пакет, без дополнительного пополнения TRX. Длительность определяется сервисом.
  • request_id: уникальный UUID для нового заказа. При повторе того же заказа нужно сохранять этот UUID и параметры.
  • ORDER_PENDING_OR_UNKNOWN: проверить историю в приложении или обратиться в поддержку; не повторять с новым UUID.
  • API_KEY_REQUIRED: настроить ключ в заголовках подключения.

MCP не предоставляет историю и отслеживание заказов, проверку адресов на санкции или отдельные ончейн-запросы. Инструмент цен возвращает публичный прайс, а не точную персональную стоимость перед заказом.
