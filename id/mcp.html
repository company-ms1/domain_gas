  2. Tambahkan konfigurasi

Mode koneksi

Harga dan estimasi sumber daya tersedia. Tidak perlu akun.

Konfigurasi pribadi Cursor

Tambahkan server ke ~/.cursor/mcp.json. Jika file sudah ada, tambahkan entri gasfree4you ke objek mcpServers, dengan tetap mempertahankan server lain.

mcp.json
{
  "mcpServers": {
    "gasfree4you": {
      "url": "https://www.gasfree4you.com/mcp"
    }
  }
}

Simpan file, mulai ulang Cursor, dan periksa server di pengaturan MCP.

Dokumentasi Cursor ↗

Tambahkan melalui Claude Code CLI

Jalankan perintah di terminal. Cakupan user membuat server tersedia di seluruh proyek Anda.

Terminal
claude mcp add --transport http --scope user gasfree4you https://www.gasfree4you.com/mcp

Buka sesi Claude Code baru dan jalankan /mcp untuk memeriksa koneksi. Untuk mengganti mode, hapus entri lama terlebih dahulu: claude mcp remove --scope user gasfree4you, lalu tambahkan kembali.

Dokumentasi Claude Code ↗

Konfigurasi Codex

Tambahkan blok ini ke ~/.codex/config.toml. Jika entri gasfree4you sudah ada, perbarui tanpa membuat duplikat.

config.toml
[mcp_servers.gasfree4you]
url = "https://www.gasfree4you.com/mcp"

Mulai ulang klien. Di Codex CLI, jalankan /mcp dan periksa alat yang tersedia.

Dokumentasi Codex ↗

Gunakan klien yang mendukung Streamable HTTP dan header HTTP kustom. Kunci API diatur secara manual, tanpa OAuth.

Kirim kunci hanya melalui header koneksi: X-API-Key: YOUR_API_KEY atau Authorization: Bearer YOUR_API_KEY. Gunakan salah satunya saja. Jangan kirim kunci di chat, URL, atau parameter alat, dan jangan publikasikan konfigurasi yang berisi kunci.

Penting saat memesan

Pemesanan energi memotong dana dari saldo akun Anda. Hubungkan kunci hanya ke aplikasi tepercaya dan periksa alamat serta parameter pembelian.

Jika agen melaporkan hasil pesanan tidak diketahui atau waktu tunggu habis, periksa riwayat transaksi di GasFree4You terlebih dahulu. Jangan buat pesanan baru sebelum hasil pesanan sebelumnya diketahui.

Perilaku konfirmasi bergantung pada klien AI dan pengaturannya: jendela konfirmasi terpisah mungkin tidak muncul.

Empat alat yang tersedia. Atur autentikasi di header HTTP koneksi, bukan di argumen panggilan alat.

Alat dan parameter MCP GasFree4You
AlatParameterAkses
estimate_transfer_feesender_wallet, recipient_walletTanpa kunci
get_energy_pricesTidak adaTanpa kunci
get_account_balanceTidak adaKunci API
order_energywallet, energy, request_idKunci API · berbayar
  • energy: 65000, 130000 atau 131000. Nilai 130000 dinormalisasi menjadi 131000.
  • Satu panggilan pesanan membeli satu paket, tanpa tambahan isi ulang TRX. Durasi ditentukan oleh layanan.
  • request_id: UUID unik untuk pesanan baru. Gunakan kembali UUID dan parameter yang sama saat mengulangi pesanan tersebut.
  • ORDER_PENDING_OR_UNKNOWN: periksa riwayat di aplikasi atau hubungi dukungan; jangan ulangi dengan UUID baru.
  • API_KEY_REQUIRED: atur kunci di header koneksi.

MCP tidak menyediakan riwayat atau pelacakan pesanan, pemeriksaan sanksi alamat, maupun kueri on-chain terpisah. Alat harga mengembalikan harga publik, bukan harga khusus akun yang pasti sebelum pemesanan.
