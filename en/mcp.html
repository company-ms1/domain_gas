Connection mode

Prices and resource estimates are available. No account needed.

Personal Cursor configuration

Add the server to ~/.cursor/mcp.json. If the file already exists, add the gasfree4you entry to its mcpServers object, keeping your other servers.

mcp.json
{
  "mcpServers": {
    "gasfree4you": {
      "url": "https://www.gasfree4you.com/mcp"
    }
  }
}

Save the file, restart Cursor and check the server in MCP settings.

Cursor documentation ↗

Add via Claude Code CLI

Run the command in your terminal. The user scope makes the server available across your projects.

Terminal
claude mcp add --transport http --scope user gasfree4you https://www.gasfree4you.com/mcp

Open a new Claude Code session and run /mcp to check the connection. To switch modes, first remove the existing entry: claude mcp remove --scope user gasfree4you, then add it again.

Claude Code documentation ↗

Codex configuration

Add this block to ~/.codex/config.toml. If the gasfree4you entry already exists, update it instead of creating a duplicate.

config.toml
[mcp_servers.gasfree4you]
url = "https://www.gasfree4you.com/mcp"

Restart your client. In Codex CLI, run /mcp and check the available tools.

Codex documentation ↗

Use a client that supports Streamable HTTP and custom HTTP headers. Configure your API key manually; OAuth is not used.

Send your key only in a connection header: X-API-Key: YOUR_API_KEY or Authorization: Bearer YOUR_API_KEY. Use just one of them. Never send your key in chat, URLs or tool arguments, and never publish a configuration containing your key.

Important when ordering

Ordering energy spends funds from your account balance. Connect your key only to trusted applications, and check the address and purchase parameters.

If the agent reports an unknown order result or a timeout, first check your transaction history in GasFree4You. Do not create another order until the outcome of the previous one is clear.

Confirmation behavior depends on the AI client and its settings: a separate confirmation dialog may not appear.

MCP REFERENCEFor developers+

Four available tools. Set authentication in the connection’s HTTP headers, not in tool arguments.

GasFree4You MCP tools and parameters
ToolParametersAccess
estimate_transfer_feesender_wallet, recipient_walletNo key needed
get_energy_pricesNoneNo key needed
get_account_balanceNoneAPI key
order_energywallet, energy, request_idAPI key · paid
  • energy: 65000, 130000 or 131000. The value 130000 is normalized to 131000.
  • One order call buys one package, with no additional TRX top-up. The service determines the duration.
  • request_id: a unique UUID for a new order. Reuse this UUID and the same parameters when retrying that order.
  • ORDER_PENDING_OR_UNKNOWN: check the history in the app or contact support; do not retry with a new UUID.
  • API_KEY_REQUIRED: configure your key in the connection headers.

MCP does not provide order history or tracking, sanctions screening of addresses, or standalone on-chain queries. The price tool returns public prices, not an exact account-specific quote before an order.
